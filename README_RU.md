# CyberLink Support — инструкция

Это учебный прототип видеосвязи и демонстрации экрана с явным согласием участников.

## Что умеет
- Комната на двух участников по общему коду.
- Участник сам нажимает «Включить камеру» или «Показать экран».
- Браузер показывает системный запрос разрешения.
- Отключение и остановка передачи доступны в интерфейсе.

## Чего не умеет
- Не управляет нажатием кнопок на Android.
- Не включает камеру/экран скрытно.
- На телефонах демонстрация экрана может не поддерживаться браузером.
- Это демонстрационный прототип: для устойчивой работы через разные сети могут потребоваться TURN-сервер и HTTPS.

## Запуск на Windows
1. Установите Node.js LTS с официального сайта, если он ещё не установлен.
2. Распакуйте ZIP в папку, например `C:\\cyberlink-support`.
3. Откройте PowerShell в этой папке.
4. Выполните:
   ```powershell
   npm install
   npm start
   ```
5. На ноутбуке откройте `http://localhost:3000`.

## Подключение второго устройства
`localhost` доступен только на самом ноутбуке. Чтобы открыть приложение на другом устройстве, оно должно быть размещено на HTTPS-хостинге, поддерживающем Node.js и WebSocket, либо доступно через безопасный HTTPS-туннель. Не отправляйте публичную ссылку посторонним. Оба участника должны открыть один и тот же адрес и ввести одинаковый код комнаты.

## Важные ограничения
- `getDisplayMedia()` обычно требует HTTPS или localhost; поддержка на мобильном Chrome зависит от версии и устройства.
- Если браузер не поддерживает демонстрацию экрана на Android, используйте обычный видеозвонок/системную демонстрацию экрана.
- STUN может не обеспечить соединение в каждой сети. Для надёжного NAT traversal добавляют TURN-сервер.
